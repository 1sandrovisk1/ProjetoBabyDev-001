# SoundWave - Projeto inspirado no Spotify

Este projeto e uma pagina front-end inspirada no visual atual do Spotify Web Player, criada com uma marca ficticia chamada **SoundWave**.

O objetivo foi praticar estrutura semantica com HTML5, estilizacao moderna com CSS3, responsividade, uso de Flexbox, CSS Grid, variaveis CSS e efeitos de hover, sem utilizar JavaScript.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media queries
- Variaveis CSS

## Funcionalidades visuais

- Layout inspirado em um web player moderno de musica.
- Barra superior com logo, botao Home, campo de pesquisa e acoes de usuario.
- Sidebar com area de biblioteca, cards de playlist e links auxiliares.
- Area principal com secoes de conteudo:
  - Playlists recomendadas
  - Artistas populares
  - Singles e albuns em destaque
  - Estacoes de radio populares
  - Paradas em destaque
- Cards responsivos com efeito hover.
- Botao de play exibido ao passar o mouse sobre cards de musicas, artistas e paradas.
- Footer interno com links organizados por categoria.
- Barra inferior de preview com chamada para cadastro.
